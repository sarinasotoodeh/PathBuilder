# PathBuilder – Ellehacks 2026

A career-pathway web app that matches your interests to a degree, college program, or apprenticeship — built in 36 hours.

## Overview

PathBuilder was built in 36 hours at Ellehacks 2026 by a team of 4. Users answer a short questionnaire about their interests and goals, and a JS-based scoring system matches them to relevant degrees, college programs, or apprenticeship paths, alongside a directory of Ontario schools.

The team scoped features tightly to fit the 36-hour build window, cutting lower-priority ideas to ship on time, and attended a Git/GitHub workshop mid-hackathon to help manage the live codebase.

## Features

- Interest/goals questionnaire
- JS scoring engine that matches answers to degree, college, or apprenticeship paths
- University/college directory with logos
- (Stretch goal that didn't make the cut in time: AI-generated suggestions)

## Tech stack

HTML, CSS, JavaScript — no backend, scoped to fit the hackathon's 36-hour timeline.

## How to run

Just open `index.html` in a browser — no build step or server needed.
